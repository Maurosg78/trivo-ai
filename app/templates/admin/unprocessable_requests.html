Guía para Implementación

Instrucciones para añadir nuevos tipos de recetas:

  1. Añadir el nuevo tipo al diccionario KNOWN_RECIPE_TYPES en app.py.
  2. Actualizar la función can_process_request para permitir el nuevo tipo.
  3. Crear una clase de procesamiento específica o extender la existente.
  4. Actualizar la interfaz para mostrar el nuevo tipo disponible.
  5. Implementar instrucciones específicas en generate_instructions.
