# Registros Diarios de TRIVO-AI

Este directorio contiene los registros diarios de trabajo en el proyecto TRIVO-AI, siguiendo la metodología de sprints de GitHub Projects.

## Estructura de Sprint Actual

Actualmente estamos en el Sprint 3 (15 Abril - 29 Abril 2024) enfocado en la implementación de la interfaz para visualización de logs y estadísticas de ayuda, integración con los endpoints ya creados.

## Estado del Sprint

Para ver el estado actual del sprint, visita nuestro tablero Kanban:
- [Tablero Kanban](../../KANBAN.md)
- [Proyecto GitHub](https://github.com/users/Maurosg78/projects/12/views/1)

## Cómo usar estos registros

1. Cada día de trabajo debe tener su propio archivo README_YYYY_MM_DD.md
2. Usa el archivo [TEMPLATE.md](TEMPLATE.md) como base para crear nuevos registros
3. Al finalizar tu trabajo diario, documenta lo realizado siguiendo la estructura del template
4. Asegúrate de que tus tareas estén alineadas con el sprint actual según el tablero Kanban
