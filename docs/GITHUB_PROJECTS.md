# GitHub Projects - Configuración

## Configuración de GitHub Projects para TRIVO-AI

Este documento describe cómo hemos configurado GitHub Projects para gestionar nuestros sprints siguiendo la metodología Scrum.

## Estructura de Nuestro Tablero

1. **Backlog**: Lista priorizada de todas las tareas pendientes
2. **Sprint Actual**: Tareas comprometidas para el sprint en curso
3. **En Progreso**: Tareas que se están desarrollando actualmente
4. **Revisión**: Tareas completadas que necesitan revisión
5. **Terminado**: Tareas completadas y revisadas

## Etiquetas de Tareas

- **S{N}-{XXX}**: Identificador de tarea (S = Sprint, N = número de sprint, XXX = número secuencial)
- **bug**: Problemas o errores
- **feature**: Nuevas funcionalidades
- **documentation**: Mejoras en documentación
- **enhancement**: Mejoras en funcionalidades existentes

## Proceso de Sprint

1. **Planificación de Sprint**: Al inicio de cada sprint (cada 2 semanas)
2. **Reuniones Diarias**: Sincronización breve sobre progreso y obstáculos
3. **Revisión de Sprint**: Al final del sprint para mostrar lo logrado
4. **Retrospectiva**: Reflexión sobre lo que funcionó y lo que se puede mejorar

## Integración con Commits

Para conectar el trabajo con las tareas, usar en los mensajes de commit:

```
S3-001: Implementa página de estadísticas de ayuda
```
